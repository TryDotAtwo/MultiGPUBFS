# Lossless SHARD_AB state keys

Current public specialization is enabled only for the matched inverse-closed LRX permutation action whose normalized full state fits128bits. Every other graph retains the general full-state equality path. Fingerprint-only legacy native reference mode remains available solely as a historical timing baseline; it is never selected by the exact public bridge.

For alphabet size a use b=max(1,ceil(log2(a))). Concatenate all n normalized symbols into nb bits, requiring nb<=128. Fixed-width concatenation is injective: decoding each b-bit slice recovers every coordinate. Relabeling is bijective on vectors and commutes with position permutations, so it preserves the graph. No probabilistic collision assumption is used. For (14,1), nb=56; for (15,4), nb=60; 25 distinct labels require125bits. Larger unproved domains fail specialized admission and use the general backend.

A two-round Feistel permutation mixes the two64-bit halves before owner/shard routing. Forward: L'=L xor f(R xor c1); R'=R xor f(L' xor c2). Reverse in the opposite order. This is bijective for any f, so mixing preserves injectivity while spreading owner prefix bits. Hash-table bucket collisions are resolved by comparing the complete128-bit lossless key.

The Rust root key, CUDA full-state/archive/debug key and directly generated child key use the same layout and permutation. Child keys are packed directly from immutable parent states and generator position maps; full children are materialized only after acceptance. This removes the64-byte GEMM partial plane per candidate. Output keys use aligned16-byte stores; misaligned output is rejected. Native allocation admission accounts only for the compact permutation map; no old hash weights/partial buffers are charged or allocated for the exact key path. Startup proves all reachable labels fit b bits because every admitted generator is a permutation.

The codec identity is bound to archive and bootstrap digests, native receipts and profile cache schema12. A pure native key-info capability gate rejects older binaries that could silently ignore the new mode. Unsupported matrix/non-LRX or >128-bit key domains cannot enter this specialization.
