# dev41 packaged SM86 acceptance, 21 November 2026

This is a development candidate. The default backend remains `legacy`; explicitly select `segmented24` or `permutation_bitmap` for the new modes. These results do not establish a fit or a speed on B200, S14, or all graphs.

## S12 performance on the exact packaged artifact

Eight RTX 3060s, exact transport, eight shards, four owner lanes, `balanced`, `segment_rows=2^32`, 1,048,576 allocation rows per bank, initial batch 8192, autotune off, and the same benchmark script. All cases completed all 67 layers (479,001,600 states). Every layer size matched the Mahonian oracle; the last two layers were checked as full state sets without duplicates. Intermediate state sets were not exhaustively compared. The 28–38 window has 259,128,390 new states and 2,829,700,863 generated edges.

Rows are listed in execution order. Other bitmap runs and hash runs were separated by the initial hash comparisons. All were exclusive of foreign compute processes at the start and completion of each run. One-second `nvidia-smi` samples may miss short peaks, and include allocations beyond these backends; they are not instantaneous allocation accounting. Actual rank allocation receipts and environment details are in the archives. The worst rank's observed `peak_live_rows` was 9,640,704 for bitmap and 9,548,940/9,548,010 for hash off/on.

Bitmap median BFS was 116.966 s off and 125.931 s on; off range 97.363–118.596 s and on range 117.087–140.122 s. This sample is variable and does not reproduce the advantage reported for the earlier binary in the [integrated follow-up](2026-11-21-integrated-followup.md). The binaries differ, so the cause is not established. Recovery remains opt-in. The hash comparison consists of one run per setting.
