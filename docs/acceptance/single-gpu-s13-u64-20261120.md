# Single-GPU S13 bitmap and 64-bit cumulative count

On 2026-11-20, the published dev39 SM89 components (native source
`2b97b094af3f94c250bd099004024a520c5238f4`) ran the Coxeter S13 graph on
one physical RTX 4090 24 GiB, driver 580.142. The released baseline was used:
no grouped or batch acceptance path is claimed.

* COMPLETE: 6,227,020,800 distinct states, 79 layers, 1,113.331055471 BFS seconds.
* Every layer count matched a separately constructed Mahonian polynomial.
  The two final layers were also checked as exact full state sets against
  the reversed permutation and its twelve adjacent swaps on the rented GPU.
* Bitmap domain 6,227,020,800 bits used 778,377,600 bytes. Peak live rows
  reported by the runtime across its three banks: 885,894,886. The
  configured segment ceiling was 2^32; actual allocations had 1,048,576
  rows per bank, eight shards, eight owner lanes, active batch 1,024 and
  exact exchange. No source retries occurred.
* The highest 1-second nvidia-smi sample was 13,211 MiB, not a precise
  instantaneous peak. The report gives 11,777,612,544 allocated segment bytes,
  separately from the bitmap and other allocations. The cold reserve was 2 GiB.

This is a real end-to-end single-rank traversal past 2^32 cumulative visited
states. It does not demonstrate 2^32 simultaneously live state rows on one GPU,
nor B200/B300, multi-node or all-graph acceptance. The complete final layer sets
were checked on the rented GPU; raw state files are not in the evidence archive.

[Evidence archive](single-gpu-s13-u64-evidence.tar.gz), SHA-256
`447eeabd62631322d43c5bda142d0755b4f86396a3b81a007669ab96d78f5992`,
includes exact source graph and launch geometry, the benchmark and final-layer
check scripts, binary SHA-256s, report, sampled GPU telemetry and check summary.
The final-layer check script requires the original state file, which is omitted
from this public archive.
