# Native pip dev31

BFS has no work deadline by default. Use NativeOptions(max_seconds=None) or omit the field. Explicit positive limits still work; zero means unlimited in the CLI/native wire protocol. Startup, queries, retirement, diagnostic stages, and scheduler job limits remain separate.

Transient ESTALE reads of persistent phase/response files retry three times with fresh opens. Invalid identities, corrupted JSON, permission errors and persistent I/O failures are not accepted; no computation is restarted.

The eight-GPU UT diagnostic distinguishes a correct insufficient prefix from a wrong prefix. An unmeasured tuner result is inconclusive rather than a verified production pass. Fixed traced probes have a longer bounded allowance within the overall diagnostic budget.

Persistent workers retain profile results for compatible graph/runtime/device/configuration identities. Cache hits still validate memory admission. New graph identities or changed conditions may require bounded measurements. This is not a claim of a globally optimal profile.

Validation boundaries and exact measured results are in the accompanying acceptance JSON. New changes tested on 2xRTX3060; the client's eight-GPU server must run the published build to establish environment-specific acceptance.
