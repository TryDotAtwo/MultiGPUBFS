# S11 archive submission A/B on 2xT4

Status: **PASS**

The test uses source `50770121362d889d31d6e540c383376824a66451`
and Kaggle notebook `trydotatwo/mgbfs-s11-archive-a-b`, version 2. Each mode
uses identical preallocated GPU and pinned-memory capacities. The only changed
operation is submission of every finalized layer to the mandatory archive lane.
Each run reproduces all 39,916,800 states and 56 exact S11 layers.

The measured search-path cost of archive submission is 0.351476528 seconds,
or 9.7837%. Parquet conversion, Hugging Face upload and final durable commit are
outside this number. Thus archive work is successfully overlapped but is not
free: its D2H submission/event path costs about ten percent on this workload.
The off mode is an explicit benchmark-only switch and is not a valid production
output contract.
