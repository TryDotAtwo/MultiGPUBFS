The run exposed two independent contract bugs before the passing version:

1. A value named as a per-rank capacity was passed to `EQUAL_GLOBAL`, which
   split it across the two ranks and stopped with `FUTURE_FATAL_1`. The notebook
   now declares the actual cluster-wide capacity explicitly.
2. The archive configuration digest included `rank`, so valid rank archives
   from the same run failed atomic promotion with `STREAM_CONFIG`. Rank remains
   in every archive frame, while the configuration digest is now cluster-wide.

The final rank archives have the same configuration digest,
`9d83c8ee1a1343dad1dc6a9c64ced5f2ea0f56a12a603419351849ea4341fa78`,
and contain 19,959,450 and 19,957,350 states respectively. Their sum and the
per-depth sums match the exact S11 cardinality and layer distribution.
