# Cayley quotient BFS, owner activation, and path lifting

Algebraic owner blocks invite a second BFS on the much smaller block graph. The
meaning of that BFS depends on whether block transitions are genuine quotient
transitions or merely existential edges between sets of states.

For a normal subgroup of a Cayley graph, quotient distance has an exact fiber
interpretation. For an arbitrary partition, block distance is generally only a
lower bound and can be spuriously finite.

This note develops those boundaries without proposing a runtime partition.

## 1. Normal Cayley quotient

Let `G` use right multiplication by generators `S`, let `H normal G`, and let

```text
pi(g) = gH.
```

Every labeled transition projects consistently:

```text
g --s--> gs
gH --sH--> gsH.
```

Let `d_G(e,x)` be directed word distance in the original Cayley graph and let
`d_Q(H,gH)` be directed distance in the quotient Cayley graph generated by the
images of `S`. Then

```text
d_Q(H,gH) = min_(x in gH) d_G(e,x).
```

### Projection direction

Every word reaching `x in gH` projects to a quotient word of the same length,
so

```text
d_Q(H,gH) <= d_G(e,x)
```

for every member of the fiber.

### Lifting direction

A quotient word is still a word in the original generators. If it reaches
`gH`, its product is some concrete `x in gH` reached in the same number of
steps. Therefore the shortest quotient word supplies a concrete fiber member
at that length, proving the reverse inequality to the minimum.

The equality is about distance to the whole coset fiber. It does not say that
every element of `gH` has the quotient distance.

## 2. Earliest owner-block activation

With one owner block per coset and source `e`, define

```text
alpha(C) = min { d_G(e,x) : x in C }.
```

For the normal quotient,

```text
alpha(gH) = d_Q(H,gH).
```

Thus quotient BFS gives the first exact depth at which a coset owner can receive
an original frontier state. It does not give the later occupancy profile

```text
f_(d,C) = |F_d intersect C|.
```

An owner can activate early and remain lightly loaded, or activate late and
receive a large frontier. Quotient distance predicts first contact, not work,
bytes, duration, or capacity peak.

When several cosets map to one GPU, the earliest possible activation is the
minimum quotient distance among its assigned cosets.

## 3. Quotient shells aggregate first arrivals, not full frontiers

Let

```text
Q_i = { C : alpha(C)=i }.
```

`Q_i` is the quotient frontier of owner blocks first touched at depth `i`.
Original frontier `F_d` can occupy blocks from several quotient depths `i<=d`
because traversal continues inside already activated fibers.

Therefore

```text
number of active owners at depth d
```

is not generally `|Q_d|`, and quotient frontier width is not a proxy for
original frontier width. The cumulative set of potentially activated blocks is
the quotient ball, but actual per-level load requires fiber-resolved counts.

## 4. Arbitrary existential block graphs

For any partition `P` of a graph, one can create a block graph with an arc

```text
A -> B
```

when at least one concrete edge goes from some state in `A` to some state in
`B`. Every concrete path projects to a block walk, so

```text
d_block([s],B) <= min_(x in B) d_G(s,x).
```

The inequality can be strict because consecutive block arcs may use
incompatible representatives.

### Minimal spurious-path fixture

Use concrete states `{s,x,y,t}` and edges

```text
s -> x,
y -> t.
```

Partition them into

```text
A={s}, B={x,y}, C={t}.
```

The existential block graph contains `A->B->C`, so it reports block distance
two from `A` to `C`. But there is no concrete path from `s` to `t`: the first
edge reaches `x`, while the second block edge exists only from the incompatible
representative `y`.

Thus an existential owner graph can invent both a shorter distance and
reachability itself.

## 5. The missing condition is path lifting

Exact fiber distance requires that every quotient step be realizable from the
representative reached by the preceding lifted steps. A sufficient labeled
transition-congruence condition is

```text
x ~ y  =>  succ_s(x) ~ succ_s(y)
for every generator label s.
```

Then each label has a representative-independent class destination and every
quotient word lifts step by step. Bisimulation supplies a more general
existential matching condition when transitions are nondeterministic.

Normal-subgroup Cayley quotients satisfy the deterministic congruence. A hash
partition does not. Left-coset owner blocks `gH` for a nonnormal subgroup preserve
the locality theorem of note 167, but their outside-label destinations are not
generally representative-independent; an existential block BFS therefore
cannot automatically be used as exact owner-activation distance.

## 6. Schreier orbit blocks

For states `K\G` grouped into right `H`-orbits `K\G/H`, every label from `H`
remains inside its orbit. Outside labels need not induce a well-defined map on
orbit blocks.

An orbit-block transition is exact for labeled quotient BFS only when the orbit
equivalence is stable under every allowed successor label. Without that
congruence, the orbit graph still supplies a projected lower bound, but can
admit incompatible-representative paths just like the generic fixture.

The fact that blocks arise algebraically does not by itself prove path lifting.
Subgroup locality and quotient correctness are separate properties.

## 7. Lower bounds versus scheduling predictions

A sound projected distance can be useful as:

- a lower bound on concrete distance to a block;
- a proof that a block cannot receive frontier states before some depth;
- a compact description of possible inter-block motion;
- a validation target for first observed owner activation when equality is
  proved.

It cannot by itself predict:

- number of states entering the block at each depth;
- support-arc or routed-record multiplicity;
- owner contention or bytes;
- how long internal traversal remains in the block;
- exact target distance to one representative;
- executable connector words without lifting metadata.

## 8. Multi-GPU validation record

For an algebraic partition, preserve:

1. action side, subgroup, coset/orbit convention, and generator labels;
2. whether transitions are congruent, bisimilar, or merely existential;
3. quotient distances and their claimed meaning: exact fiber, lower bound, or
   heuristic only;
4. predicted first activation `alpha(C)` where proved;
5. observed per-depth `f_(d,C)` and first nonzero depth;
6. concrete replay of quotient paths when lifting is claimed;
7. separate state, support-arc, routing, and byte matrices;
8. the mapping from algebraic blocks to physical GPUs.

Agreement of first-activation depths is useful bounded evidence for the
partition/action convention. It does not validate complete frontier contents
or performance scaling.

## 9. Rejected implications

- Quotient distance equals the distance to every fiber member.
- A quotient shell equals the set of owners carrying the current frontier.
- Equal quotient and concrete diameters imply equal frontier profiles.
- Any existential block graph has path lifting.
- Any subgroup-derived partition is a transition congruence.
- Subgroup generator locality proves outside-label quotient correctness.
- A lower owner-graph distance predicts owner load or communication volume.
- A block path can be replayed without tracking compatible representatives.

## 10. Current synthesis

Normal Cayley quotients have a clean metric meaning: quotient distance is exact
distance to the nearest member of a coset, and therefore the first possible
activation depth of that coset owner. This is weaker than element distance and
much weaker than a load prediction.

For nonnormal, Schreier-orbit, hash, or arbitrary partitions, a small owner
graph is exact only after a transition-congruence or path-lifting proof.
Otherwise it is an over-approximating abstraction whose BFS distances are lower
bounds and whose paths may be spurious.
