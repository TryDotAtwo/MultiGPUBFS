# Trace quotient versus equality in a Cayley group

REF-027/028 can be placed in a standard algebraic hierarchy. Doing so also
prevents the phrase "commuting moves" from carrying more meaning than it has.

## 1. Words

Let `Sigma` be the move alphabet and `Sigma*` its free monoid of finite words.
At this level two different sequences are different objects, even if applying
them gives the same puzzle state.

For a symmetric generating set it is often cleaner to start from base
generators and formal inverses. The current probe instead enumerates the 24
signed move symbols directly; its explicit inverse table supplies the same
operational information for the bounded experiment.

## 2. Static trace quotient

Let `I` contain pairs of letters whose actual generator permutations commute.
The congruence `equiv_I` is generated only by

```text
u a b v  equiv_I  u b a v     when (a,b) is in I.
```

The quotient `M(Sigma,I) = Sigma* / equiv_I` is the partially commutative or
trace monoid. Cartier and Foata developed monoids defined by commutation
relations; Mazurkiewicz later used traces as partial orders of action
occurrences in concurrency.

Conventionally `I` is symmetric and irreflexive. The REF-027/028 code obtains
its Boolean table by directly comparing permutation products, so its diagonal
entries are true. This implementation detail is inert: swapping two identical
adjacent letters returns the identical word and adds no closure edge. Removing
the diagonal gives the conventional independence relation without changing
any reported class.

This supplies a precise interpretation of REF-027's swap closure. It is not a
general group normal form and does not include inverse cancellation, finite
orders, braid relations, or arbitrary consequences of a puzzle presentation.

## 3. Evaluation in the represented group

Let `G` be the subgroup generated by the move permutations and let

```text
eval: Sigma* -> G
```

multiply the corresponding generators in the declared action convention.
Because every pair in `I` really commutes, evaluation is constant on trace
classes and factors through the trace quotient:

```text
Sigma* -> M(Sigma,I) -> G.
```

Therefore

```text
same trace  =>  same group element.
```

The converse need not hold. Trace equality is a sound sufficient certificate
for endpoint equality, not a complete decision procedure for this group.

Globally, incompleteness is already obvious from inverse and order-five
relations. The more focused REF-027/028 question restricts attention to
geodesic words of one fixed length, where such nongeodesic witnesses have been
removed. Through length three every endpoint fiber contains one trace class;
at length four, 480 fibers contain two.

## 4. Relation to graph groups

A graph group, now commonly called a right-angled Artin group, is generated by
vertices of a graph with only the commutator relations associated with graph
edges. Green's graph-product normal-form work formalizes the special world in
which reduced representatives are unique up to shuffling commuting syllables.

The current Megaminx move group is not being claimed to be such a graph group.
There is a natural homomorphism from the graph group defined by the static
face-commutation graph to the permutation group generated by the moves. The
order-five relator words and the REF-028 commutator relator words lie in its
kernel. REF-028 does not determine whether these are independent normal
generators of that kernel, nor a presentation or minimal relator basis.

This is the exact boundary of the experiment:

- it proves the two geodesic words are unequal under static trace shuffling;
- it proves their evaluated permutation elements are equal;
- it does not prove that the resulting length-eight relator is independent of
  every other known relation.

## 5. Why conjugation is not state-dependent generation

The REF-028 pattern is

```text
g(h k h^-1) = (h k h^-1)g,
```

or `[g, h k h^-1] = 1`. This is a centralizer statement inside `G`: the
composite element `h k h^-1` belongs to the centralizer of `g`.

Under right Cayley multiplication, the labeled successor remains

```text
x --k--> xk
```

at every vertex `x`. No dynamic move table is implied. Conjugation constructs
a different group element whose permutation support may be the image of the
support of `k` under `h`. The static trace alphabet simply has no single letter
for that composite element.

This distinction matters for GPU and multi-GPU thinking. Ordinary BFS should
still deduplicate exact states. Trying to recognize every algebraic reason for
a duplicate inside the hot path would solve a richer word/presentation problem
than distance BFS requires, with no demonstrated performance benefit.

## 6. Consequences for the shortest-path DAG

For a state `v` at distance `d`, consider the fiber of all geodesic length-`d`
words evaluating to `v`. There are successive quotients:

```text
word occurrences
    -> static trace classes
    -> exact group/state endpoint.
```

REF-028 proves that the second arrow first merges distinct trace classes at
current Megaminx depth four. BFS visited dedup performs the final endpoint
quotient directly. It need not know whether a merge came from a commutator,
conjugated commutator, power relation, or a long overlap of relators.

If the output contract asks for all shortest words, trace classes, or a
presentation-aware certificate, state-only visited metadata is insufficient.
That is an output-contract issue, not a defect in distance BFS.

  [Concurrent Program Schemes and their Interpretations](https://tidsskrift.dk/daimipb/article/view/7691),

  groups whose defining relators are generator commutators.
- C. Löh,
  [Geometric Group Theory lecture notes](https://loeh.app.uni-regensburg.de/teaching/ggt_ws1415/lecture_notes_old.pdf),
  sections 3.2 and 5.2. These give the Cayley graph and word metric conventions
  used to connect geodesic words with BFS distance.

Servatius's centralizer theorem concerns graph groups specifically. It is
useful surrounding theory, but REF-028's finite permutation group is not shown
to satisfy that theorem's graph-group hypothesis; therefore the experiment is
not presented as an application of the theorem.
